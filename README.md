# Student-Record-System

A simple student record management system written in PHP which allows users to add, view, edit, and delete student records.

## index.php

This file redirects the user to the student records page.

## add.php

This file allows the user to enter student details such as name, roll number, and course and add a new student record.

## view.php

This file displays all the student records and provides options to edit or delete a record.

## edit.php

This file allows the user to update the existing student information.

## delete.php

This file deletes the selected student record from the system.

## students.php

This file stores the student records generated by the PHP application.

## Pre-requisites

You must have XAMPP (Apache) and PHP installed on your system.
